SDN NEGERI WARAKAS 3 — SATU SERVER / SEMUA PERANGKAT

CARA PALING MUDAH:
1. Ekstrak ZIP.
2. Di komputer yang dijadikan SERVER, klik MULAI_LANGSUNG_WINDOWS.bat.
3. Buka http://localhost:8080/ di komputer server.
4. Dari HP/laptop lain yang satu jaringan, buka http://IP-KOMPUTER-SERVER:8080/
5. Semua perangkat memakai LINK YANG SAMA. Data yang disimpan otomatis dikirim ke server dan dibagikan ke perangkat lain.

CONTOH:
Jika IP komputer server 192.168.1.10, semua perangkat buka:
http://192.168.1.10:8080/

DATA SERVER disimpan di server-data.json.
Tidak perlu membuka file HTML langsung. Jalankan server terlebih dahulu.

Catatan: komputer server harus tetap menyala agar perangkat lain dapat terhubung.
